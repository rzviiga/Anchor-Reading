# Anchor Overlay 0.3.0

目标：减少漏词，保持 0.2 的原生粗体词首绘制效果。

## 修改

- OCR 最小字高由画面高度的 0.4% 改为 6 个捕获像素；整行置信度门槛由 0.5 改为 0.2。新增候选仍需通过逐词像素匹配，英文范围、完整词框及倾斜保护继续保留。
- 每行先匹配长词，积累字体信息后处理短词。成功缓存也传播字体信息；失败缓存记录当时字体，字体信息改变后重试。
- 原匹配失败后尝试其他已安装的系统及常见字体，不下载字体，也不把缺失字体当成有效候选。
- 对最接近的两个候选分别进行 0.5 / 0.25 像素位置及尺寸调整，每词最多额外渲染 32 次小字形模板；复用灰度缓冲区。保留原来的匹配通过分数和宽高比约束。
- 原采样失败后允许较低对比度文字进入匹配，背景一致性及异色像素限制保持不变。
- 粗体输出、词尾像素复制、前景/背景色空间、滚动隐藏以及刷新调度未修改。
- 菜单增加识别词数与增强词数。识别词数指通过英文、尺寸和方向筛选、进入字体匹配的词；并非屏幕实际总词数。

## 验证边界

本版按用户要求仅编译、签名和打包，没有运行测试、性能基准或屏幕 OCR，也没有启动应用。覆盖率和实际耗时尚未测量。字体匹配补偿会增加失败词的处理成本；不承诺全屏识别或特定延迟。

构建：`python3 scripts/build.py`

打包：`python3 scripts/package.py`
