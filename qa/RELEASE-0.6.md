# Anchor Overlay / AnchorRead 0.6.0

为节能模式增加键盘触发更新，以及输入法候选窗等浮动窗口的避让。常规捕获调度和原生粗体字形算法保持不变。

## 键盘

- 使用主运行循环上的 listen-only CGEvent tap，接收 keyDown、keyUp、flagsChanged。始终原样返回事件，不提取字符、不注入事件、不记录键盘历史。
- 只在节能模式运行时安装监听。菜单提供输入监控权限授权、状态与重试；未授权不假装键盘监听生效，保留鼠标更新与手动刷新。
- 输入立即隐藏面板并使旧截图、OCR 结果失效；连续输入合并为一个可取消的 0.5 秒静默等待，加上截图流程原有 0.3 秒防抖后再更新。
- 按键或修饰键仍按住时不恢复；静默等待末尾和用户操作时检查已追踪的按键状态，补偿丢失松开事件，不增加周期键盘计时器。监听中断时先隐藏，后续按键或鼠标操作可恢复。
- Command+A 和 Shift+导航键进入选区保护，Command+C 保留保护。未覆盖所有应用自定义快捷键。

## 候选窗

- 节能覆盖层使用浮动层级，常规模式层级不变。
- 单次截图前、识别后各读取一次可见窗口的层级和几何信息，排除本进程，保护所有高于普通窗口层级的窗口区域。
- 合并前后区域，跳过相交补丁，避免重绘截图中的候选框或遮住处理期间出现、移动的候选框。位置查询失败时不显示该轮补丁。
- 不根据输入法名称猜测候选窗，也不读取跨应用组词状态；普通窗口内自绘候选、安全输入和延迟弹窗仍有局限。其他浮动面板也可能不显示强调。
- 中英文 README、帮助和版本同步更新。

## 验证边界

仅编译、签名、打包；按用户此前要求未运行屏幕/键盘监听、权限请求、OCR、输入法测试或能耗测试。不宣称所有输入法均兼容，也没有实际延迟或节电测量。

构建：`python3 scripts/build.py`

打包：`python3 scripts/package.py`
