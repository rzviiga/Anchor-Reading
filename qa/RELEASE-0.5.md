# Anchor Overlay / AnchorRead 0.5.0

增加可选的「节能模式（按需截图）」，默认关闭，设置通过 UserDefaults 持久保存。关闭后沿用 0.4 的持续捕获流程，OCR 和字形渲染未修改。

## 实现

- 两种捕获方式使用同一个界面协议。常规 CapturePipeline 的采样、刷新和调度逻辑保持不变。
- 新 SnapshotCapturePipeline 使用 SCScreenshotManager.captureSampleBuffer，不创建或启动 SCStream，也不创建周期计时器。
- 开启和交互结束后，经 0.3 秒单次防抖延迟，依次捕获各显示器并在串行队列上执行原 OCR / 原生粗体匹配。
- 新交互取消旧的等待任务并使旧结果失效；截图后、OCR 后均检查版本。鼠标按住、选区保护或应用菜单打开时暂停新任务。处理完所有显示器后不再安排捕获、像素检查或识别。
- 切换模式和退出会取消待执行任务，等待在途截图或 OCR 结束，防止两个模式同时工作。退出前的结果不会在新模式中显示。
- 保持排除本应用，处理后释放整帧像素；不保存截图。两种模式都需要屏幕录制权限。
- 菜单提供手动刷新和静止休眠状态；应用切换、桌面空间切换及原有鼠标交互可触发更新。
- 中英文 README 同步加入开关、行为对照、刷新方式和限制。

## 限制与验证

按需模式没有后台画面变化检测，网页自动加载、动态画面和应用内纯键盘操作可能留下过时覆盖层，需要手动刷新或切回常规模式。没有增加浏览器扩展、独立阅读器、辅助功能文字提取或键盘监听权限。

本版仅编译、签名和打包，按用户此前要求未运行测试、应用、屏幕截图、OCR 基准或能耗测量。没有实测节电百分比或恢复延迟。“静止休眠”只描述捕获与 OCR 调度，覆盖层合成和输入监听仍可能产生开销。

构建：`python3 scripts/build.py`

打包：`python3 scripts/package.py`
